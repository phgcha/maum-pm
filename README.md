# maum-pm

마음AI(Maum AI) 프로젝트 매니지먼트(PM) 문서 및 히스토리 관리용 개인 리포지토리입니다.

## 디렉토리 구조

- **`HanwhaOcean/`**: 한화오션 곡블록 자율용접 AI 기술 개발 과제 (`P-WORV777-24`) 현황, 프로토콜, 회의 자료
- **`DusanBobcat/`**: 두산밥캣 데이터 인프라(7대 툴체인) 명세, 재사용 계획 및 회의록
- **`HanwhaAerospace/`**: 한화에어로스페이스 K9/K10 피지컬 AI 자율임무실행기술 선행연구 현황
- **`ontology/`**: 사내 온톨로지 개념, 설계, 플랫폼 및 운영 브리프
- **`tools/`**: 회의록 전사·화자 분리(`meeting-transcribe`) 등 PM 보조 스크립트
