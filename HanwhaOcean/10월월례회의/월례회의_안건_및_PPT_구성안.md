## 2. Google Slides 편집 방식

> **반영 현황 (2026-10-27)**: 표지 뒤 2~19번에 신규 슬라이드 18장과 Reference 구분 슬라이드를 넣었고, 기존 슬라이드 17장은 20~36번으로 옮겼다. 원본 사본은 `한화오션 Monthly (Oct) - backup 20261027`로 보존했다. 사진과 영상 자리는 파일명이 적힌 회색 점선 프레임이며, Drive 업로드 후 교체한다. 발표자 노트는 신규 슬라이드 전체에 입력했다.

### 2.1 최종 슬라이드 순서

```
[1]      표지 (기존 1번, 수정 없음)
[2~18]   신규 슬라이드 17장 (본 구성안 §3, 3번·4번 분할 기준)
[19]     구분 슬라이드: "Reference — 기존 초안 (10/26 버전)"
[20~36]  기존 2~18번 슬라이드 17장 (10/27 오전 추가된 섹션 슬라이드 포함, 순서 유지, 내용 수정 없음)
```

- 3번·4번을 한 장으로 유지하면 신규 슬라이드가 장당 1장씩 줄고 이후 위치 번호도 함께 당겨진다.
- 분할 판단 기준: 16:9 슬라이드에 넣었을 때 Gantt 행 이름과 날짜를 회의실 화면에서 읽을 수 없으면 분할한다. KOM2 Gantt는 40행 이상이라 좌우 배치 시 분할이 기본값이다.

### 2.2 작업 절차

1. 편집 전 원본 사본 생성 (`한화오션 Monthly (Oct) - backup 20261027`)
2. 신규 슬라이드를 표지 바로 뒤(index 1)부터 순서대로 삽입해 기존 2~17번을 자동으로 뒤로 밀기
3. 기존 슬라이드 앞에 Reference 구분 슬라이드 1장 추가
4. 로컬 미디어를 Drive 폴더 `한화오션_10월월례회의_media`에 업로드한 뒤 슬라이드에 삽입
   - 사진: 이미지 삽입
   - 영상: Drive 영상 삽입 (자동 재생 끔, 시작 구간 지정)
5. 슬라이드별 발표자 노트 입력 (§3의 "노트" 항목)
6. 기존 Reference 슬라이드의 도식(시스템 구성, 리드타임 차트, 시편 3단계 이미지)은 복제해 신규 슬라이드에 재사용
