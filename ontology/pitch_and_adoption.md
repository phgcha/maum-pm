## 1. 경영진 메모 구조, 1~2장

| 순서 | 항목 | 내용 |
| :--- | :--- | :--- |
| 1 | 문제 | 사내 측정값으로 제시. 참고 수치로 Atlassian 2025년 조사의 "리더와 팀이 시간의 25%를 답 찾기에 소비" 인용 |
| 2 | 지금인 이유 | Gartner 2025년 2월 예측은 AI 준비 데이터가 없는 AI 프로젝트의 60%가 2026년까지 포기. MIT NANDA 2025년 7월 예비 보고서는 외부 도구 도입의 배포 성공률이 내부 구축의 두 배. 플랫폼을 짓지 말고 이미 산 AI가 읽을 구조를 만들자는 메시지 |
| 3 | 제안 | "AI가 읽을 수 있는 회사 기억"이라는 이름으로 규약, 스튜어드, 에이전트 프로필 세 가지. 온톨로지라는 단어는 정의와 함께 한 번만 |
| 4 | 파일럿 | 과제 1개, 6~8주, 지표 3~5개 사전 등록, 확대와 중단 기준 날짜 |
| 5 | 요청 | 스튜어드 지명 권한, 팀장 주 1시간 8주, 요금제 확인, 도구 예산 0원 시작 |
| 6 | 리스크 | 파트너 데이터 경계와 유지보수 부담, 각각의 대응 |

- 한국 보고 문화에서 1장 메모가 첨부 30장으로 불어나지 않도록 한다. 세부는 이 디렉터리 문서로 링크한다.
- 수치는 사내 측정값이 우선이다. 외부 통계는 참고로만 쓰고 출처가 추적되지 않는 수치는 쓰지 않는다. 미검증 수치 목록은 [sources.md](./sources.md) 3절.

## 2. 10분 데모

실제 과제 데이터로 두 장면만 보인다. 슬라이드보다 이 두 장면이 설득력이 크다.

| 장면 | 내용 | 보여 주는 가치 |
| :--- | :--- | :--- |
| 주간 보고 초안 | 이번 주 고객 보고 초안을 출처와 함께 생성 | 보고 작성 시간 절감, 출처 추적 |
| 결정 배경 추적 | 특정 결정의 배경을 티켓에서 Slack 스레드까지 거슬러 표시 | 인수인계, 분쟁 대응 |

## 3. 예상 반론과 답

| 반론 | 답 |
| :--- | :--- |
| Notion AI와 Slack AI가 이미 있다 | 둘 다 Outline을 못 읽고, Slack 검색에는 Linear와 Notion 커넥터가 없음. 온톨로지는 그 도구들이 읽을 구조 |
| 유지보수 부담 | 지표 5개는 자동 계산, 스튜어드 주 1시간, 폐기 규칙으로 삭제 작업 없음 |
| 비용 | v0는 0원. v1 지출은 분기 말 데이터로 결정 |
| 파트너 데이터 보안 | 보안 등급을 속성과 설정으로 강제하고 쓰기 프로필을 분리. 지금보다 경계가 명확해짐 |
| 벤더가 곧 만들어 줄 것 | Microsoft Viva Topics 종료 사례처럼 한 벤더 기능에 지식 층을 묶으면 종료 위험을 떠안음. 종료일은 미검증 |

## 4. 확산 설계

| 원칙 | 구현 |
| :--- | :--- |
| 새 도구 0 | 직원은 Linear, Notion, Slack만 그대로 사용. 규약은 Linear 팀 기본 템플릿에 프로젝트와 라벨 프리셋으로 심고, 결정 1줄 요약은 Slack 워크플로 폼으로 접수 |
| 가치 먼저 | 질문이 이미 올라오는 채널에 출처를 달아 답하는 봇을 먼저 투입. 답하지 못한 질문이 레지스트리 보강 백로그 |
| 챔피언 | 팀당 1명에게 파일럿 기간 동안 시간을 배정하고 오피스아워 운영 |
| 부드러운 점검 | 월간 유지보수 이슈로 소유자에게 알림. 공개 채널에서 지적하지 않음 |
| 측정 | 봇 질문 수, 커버리지, 결정 기록률, 스냅샷 경과일. 페이지 조회수는 보지 않음 |
| 보상 | 게시 건수에 금전 보상이나 점수를 주지 않음. 건수 보상은 양을 부풀리고 보상이 끝나면 행동이 사라진다는 사례 보고 |

**한국 조직 맥락**

- 공개 채널에 쓰기를 꺼리는 원인이 비용 대비 효익이 아니라 사회적 부담이라는 연구가 있으나, 이번 조사에서 원문 검증은 하지 못했다.
- 경영진이 직접 봇에게 묻는 모습을 보이는 상향 지시와, 기여는 폼과 봇이 대신 공개 작성하는 낮은 노출 방식을 함께 설계하는 편이 안전하다.
- 캠페인과 강제 조치만으로는 행동이 바뀌지 않았다는 보고가 있으므로, 측정 지표를 사람 평가에 연결하지 않는다.
