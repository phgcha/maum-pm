## 1. 결론

- **사내 온톨로지는 새 플랫폼이 아니다.** 회사가 다루는 대상의 종류, 관계, 규칙을 도구와 무관하게 적어 둔 공유 스키마다.
- **v0는 이미 있다.** `HanwhaOcean/project_management_protocol.md`의 도구별 역할표, `external`과 `needs-decision` 라벨, Slack 링크를 Linear 댓글에 남기는 포인터 규율, 문서 상태 어휘, 보안 등급, 4단계 에이전트 프로토콜이 암묵적 v0 온톨로지다.
- **할 일은 명시화와 전사 확장이다.** 클래스 12개짜리 스키마 파일과 도구 간 ID 레지스트리를 두고, 공식 MCP 서버로 실시간 조회한다. 새 인프라 없이 시작한다.
- **그래프 DB와 검색 플랫폼은 보류한다.** 1분기 뒤 교차 프로젝트 질문이 실제로 생기면 그때 결정한다.
