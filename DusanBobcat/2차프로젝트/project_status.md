## 2. 배경과 고객 의중

- **두산밥캣 로드맵**: 2028년 하반기 limited launch, 2030년 상용화 목표. 2027년 상반기에는 밀키웨이와 추가 축사 1곳에서 데이터 수집과 모델 개발, 상반기 북미 시장 조사 후 하반기에 해당 도메인 모델 개발 `[Slack 10/6]`
- **1순위 요구**: 같은 기체(S76)와 어태치먼트로 **다른 축사에서도 시나리오 1, 2, 3이 동작**하는 것. 김지성 팀장은 로딩/언로딩을 차량이나 어태치먼트와 무관하게 잘하는 것을 보고 싶다고 발언 `[Outline 20260930 회의록]`
- **후순위**: Cross-embodiment(S66, T76), 건설 도메인. 국내 리모델링 건설은 소형 로더(S60급)의 TPAK 대응 개발에 1년 이상 걸려 단기 제외 `[Outline 20260930 회의록]`
- **안전**: 소 감지 정지 기능을 2차 초반에 포함하기로 합의. 밀키웨이에서 소가 우리 밖으로 나오는 상황이 실제로 발생 `[Outline 20260930 회의록]`
- **내재화 한계**: 김지성 팀장은 인재 채용이 어려워 내재화는 점진적으로 하되 마음AI와의 파트너십이 불가피하다고 언급 `[Slack 10/6]`
- **인력 연속성**: 두산밥캣은 현재 인력의 연속 참여를 희망 `[Outline 20260922 사전회의]`
- **예산**: 두산밥캣은 예산 보고를 이미 마쳤고 연간 예산은 확정, phase 2에서 소진할 계획. 필수와 선택으로 나눈 견적을 요청. 11월 초 AE Strategy 예산 설명 발표 전에 고도화 과제와 도메인 확장 과제의 내용을 공유받기를 원함 `[Slack 10/8]`, `[Outline 20261029 견적 논의]`
- **의사결정 시점**: 최종 진행 결정은 2026년 11월 중이며 데모 직후 Go 가능성 언급(확정 일정 아님) `[Outline 20260922 사전회의]`. 1차의 11/12 시연 결과가 직접 영향

### 5.3 10/29 고객 피드백

- 견적 금액이 비싼지 싼지 가늠할 **레퍼런스** 요청. 예로 든 금액은 4억 원. 600시간 외주 라벨링 대비 자체 구축 비용 비교 요청
- 차일황 수석: 현재 파이프라인이 마음AI에 맞춰져 있어 4억 원의 가치가 있는지 의문
- 데이터 파이프라인의 커스텀 라벨링(서브태스크 분할)이 꼭 필요한지 질의. 마음AI는 현장 수집 수율과 System 1/2 구조를 근거로 설명
- 시뮬레이터는 **정량 품질 기준을 마음AI가 먼저 제안**하고 합의 후 구매 판단
- 사양이 확정되지 않아도 키트 **구성품 리스트** 요청
- SW 범위는 raw 저장부터 학습 전 데이터 준비까지. 에이전트 라벨링은 미포함(연동 가능, 사용은 별도 비용), 라벨링 정책서는 미포함 또는 별도 옵션
- 모델 라이선스는 기존 계약 유지 희망

근거: `[Outline 20261029 견적 논의]`, `[Slack 10/29]`, 로컬 회의록
