## 2. 프로젝트 개요

### 2.1 기본 정보

- **고객**: 두산밥캣. DBI(한국 본사)의 AE Strategy Team이 주관하고 DBNA(북미)가 기술 지원
- **내용**: 스키드 스티어 로더 Bobcat S76(S/N B5FB21620)으로 축사 분뇨 작업을 자율 수행하는 VLA 기반 PoC
- **현장**: 밀키웨이 목장 퇴비장(평택시 청북읍). 텔레옵과 학습은 판교 사무실
- **고객이 VLA를 택한 이유**: 유압 점도가 계절에 따라 달라져 rule-base가 어렵고, 수신호 2인 작업을 1인으로 줄이려는 필요 `[Outline 7/2 킥오프]`
- **시나리오**: 1 로딩/언로딩(상하차), 2 펴기(스프레딩), 3 밀기(도징). 추가로 축사 내부 묽은 분뇨 밀기 데이터 1시간 이상 수집과 주석
- **모델 구조**: System 2(Qwen 계열 VLM, 약 1Hz 판단)와 System 1(DiT 계열 action expert, 12.5~15Hz 제어)의 이중 구조. 제어는 `cmd_motion`을 TPAK CAN으로 변환해 차량에 전달
