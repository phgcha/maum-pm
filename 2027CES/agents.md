# 2027 CES 에이전트 지침

2027 CES 관련 요청을 처리하기 전에 이 문서와 [`project_status.md`](./project_status.md)를 먼저 읽는다.

## 소스 규격

| 소스 | 위치 | 용도 |
| :--- | :--- | :--- |
| Slack | `#27년ces` (`C0B6Y05A6NN`) | 관련 임원 대상 진행 상황 보고와 승인 요청 |
| Slack | `#27ces실무` (`C0CEAQDCN1F`) | 실무자 간 실시간 소통 |
| Notion | [2027 CES](https://app.notion.com/p/2027-CES-4101cbf802fa80748a29d25270e33202) | 문서 관리와 업무 트래킹 |

- `#ces_전시참가`, `#ces2026_실무진`, `#ces_데이터`는 이 프로젝트의 지정 채널이 아니다. 사용자가 요청할 때만 참고한다.

## 채널 사용 규칙

- 승인이 필요한 안건과 임원 보고는 `#27년ces` 기준으로 정리한다.
- 실무 논의의 결론은 `#27ces실무`에서 확인하되, 임원 승인 여부는 `#27년ces`에서 확인한다.
- Slack 메시지 전송과 Notion 쓰기는 사용자 확인 후 실행한다.

## Notion 접근

- `2027CES/`에서 실행한 세션의 `notion-ces` MCP 서버(`https://mcp.notion.com/mcp`)로 접근한다. 인증 방식은 OAuth다.
- 서버 설정은 `2027CES/.mcp.json`에 있으며, 이 파일은 저장소 `.gitignore`에 따라 Git 추적에서 제외된다.
- 최초 1회 `2027CES/`에서 `claude`를 실행해 서버를 승인하고, `/mcp`에서 브라우저 인증을 완료한다.
- OAuth 연결은 인증한 사용자의 Notion 권한을 따른다. 작업 대상은 위 2027 CES 페이지와 그 하위로 한정한다.
- 루트 세션의 `notion` MCP는 별도 토큰을 쓰는 다른 연결이므로 2027 CES 작업에 사용하지 않는다.
